[b]Loading Progress[/b] is a RimWorld mod that adds a detailed loading progress window to the game. It visually tracks each stage of RimWorld's startup process, showing which step is currently running. This makes waiting for RimWorld to start slightly more interesting. The mod is especially useful for those with large mod lists. No configuration required—just install and enjoy better insight into your game's loading process!

[h2]New with version v0.9 -- Loading time impact tracking[/h2]
Loosely based on the mod Startup impact, the mod now tracks and can show what mods are having what impact on your loading times. Click the loading time summary text in the bottom-right corner of your screen on the main menu to see the stats!

Since the initial release of the feature caused issues for people, the feature is disabled by default. I believe the latest version, 0.9.3, has fixed the issue, but I'm leaving the feature disabled by default for the time being. You should feel safe to try enabling it though, but if you run into any issues after doing so, please come give me a bug report so I can address it!

[h1]Mod incompatibility[/h1]
[list]
[*] RimThemes makes this mod useless, because it just covers the whole loading process with a splash screen.
[/list]

If you encounter any issues, try disabling the [b]Enable patching of initialization code[/b] setting of Loading Progress to remove the most likely source of incompatibility. If that still doesn't work (and frankly, even if it does), please leave me a bug report so I can address the problem.

[h1]Translations[/h1]
The mod is now fully translatable! Since we're loading very early on, we can't use the game's translation system because translations are literally not loaded yet, so I had to write my own. It's supposed to be fully compatible with the regular RimWorld translation organization system, so if you make a translation, and it doesn't work, please let me know so I can investigate.
